# Código da Solda — Página de Vendas

Página estática pronta para Vercel.

## Deploy na Vercel
1. Importe o repositório `ofertas-digitais`.
2. Em **Root Directory**, selecione `codigo-da-solda`.
3. Framework Preset: **Other**.
4. Deploy.
